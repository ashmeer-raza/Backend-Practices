# Snitch – Backend Practice Project

A backend practice project inspired by the **Snitch** fashion e-commerce platform, built to practice developing a modular Node.js backend with database and image-upload functionality.

### Tech Stack

- Node.js
- Express.js
- MongoDB
- JavaScript (ES6+)
- REST APIs

### Services & Tools

- **MongoDB** — Database for storing application data
- **ImageKit** — Image storage, hosting, and image management
- **Multer** — Handling multipart/form-data and file uploads
- **Postman** — API testing and development

### What I Built

- Modular Node.js backend
- MongoDB database integration
- Image upload functionality using Multer
- Image storage and management using ImageKit
- REST API foundation for an e-commerce application
- Separated application and server configuration

> **Note:** Built for learning and practice, using Snitch as a reference for the project concept and e-commerce workflow.
